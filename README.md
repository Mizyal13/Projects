# E-Commerce (Frontend & API in Separate Branches)

Project e-commerce dengan pemisahan **Frontend (UI)** dan **Backend (API)** ke branch yang berbeda.  
Branch aktif untuk UI: **`project1-eCommerce-fe`**. Frontend ditulis dominan **TypeScript**. API disiapkan pada branch terpisah. :contentReference[oaicite:0]{index=0}

> Catatan: “frontend (ui) and backend (api) just a different branch” — keterangan pada repo. :contentReference[oaicite:1]{index=1}

---

## Fitur (Ringkas)
- Katalog produk & detail produk *(UI)*
- Keranjang (cart) & update kuantitas *(UI)*
- Checkout (tergantung API) *(UI → API)*
- Autentikasi & profil (direncanakan) *(UI → API)*

---

## Tech Stack
- **Frontend:** TypeScript (dominan), CSS. Framework/bundler mengikuti branch UI. :contentReference[oaicite:2]{index=2}
- **Backend:** API pada branch terpisah (lihat tab **Branches** di GitHub). :contentReference[oaicite:3]{index=3}
